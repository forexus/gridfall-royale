# Gridfall Royale

A Tron-style 3D battle royale that runs in the browser, all in one HTML file (`index.html`). It's built with three.js r128, loaded from a CDN.

## Controls (keyboard only)
| Key | Action |
|---|---|
| W A S D | Move (relative to camera) |
| Arrow keys | Rotate / tilt camera |
| Right Shift | Fire |
| Space | Jump · open glider · leave the bus |
| Z / Right Ctrl | Scope |
| F | Enter/exit car · swap weapon |
| In car: W / S / A / D | Drive · brake/reverse · steer |

## Run
Open `index.html` in a modern browser, or turn on GitHub Pages for this repo.
